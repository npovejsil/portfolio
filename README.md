# portfolio_v2

HTML/CSS personal site. No framework, no build step.

Designed after cargo.site's M401 template (home/about desktop + frosted window aesthetic) and Readymag's archival editorial layouts (sticky index + document cards on the work page). Type set in Inter Tight as a stand-in for Diatype Variable.

Vibe-coded with [Claude Code](https://claude.ai/code).
